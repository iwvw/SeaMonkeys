# PRD（前端）：SeaMonkeys.App

> 版本：v1（2026-10-04）
> 范围：`SeaMonkeys.App`（WinUI 3）。对应主 PRD `docs/PRD.md` 与后端 PRD `docs/PRD-backend.md`。
> 关联 ADR：0001 / 0006。

## 定位

前端只负责"展示与交互"，不承担对局解析、战绩查询、服务器识别等逻辑（这些在 Core）。前端通过 Core 暴露的接口取数，通过 `SeaMonkeys.Data` 读写用户数据。

技术栈：WinUI 3 + Windows App SDK 2.x + .NET 10，复用 sox / momomi 组件（ADR-0001）。

## 界面结构

```
SeaMonkeys.App
├─ 雷达悬浮面板（主，常驻置顶）      ← 战斗中的主要界面
├─ 主窗口（详情 / 历史 / 图表）
├─ 设置窗口
├─ 托盘图标 + 右键菜单
└─ 全局快捷键
```

## 功能需求

### FE-01 雷达悬浮面板

- 无边框、置顶、可拖动、默认贴屏角，位置按 DPI 计算并记忆（复用 momomi `MiniWindow` 做法，ADR-0006）。
- 窗口常驻不销毁，显隐用 DWM cloak（复用 sox `WindowCloak`），呼出 < 100ms。
- 工具窗口属性（不进 Alt+Tab）。
- 材质：Acrylic / Mica 可切换，跟随系统深浅色（复用 sox 卡片材质）。

验收：呼出/隐藏无闪烁、无重建；拖动后关闭再开，位置保持。

### FE-02 对局展示

面板主体展示本局双方：

- 顶部概要：地图、模式、开战时间、区域、检测状态。
- 友军 / 敌军两列，每行：昵称、公会标签、舰船名（含等级/类型）、加权胜率、场次。
- 按加权胜率排序（可切换排序维度），按胜率分色。
- 隐藏档案玩家显示降级态（不显示具体数值，明确标注）。

验收：用真实 replay 触发后，24 人（或排除 bot 后的实际人数）全部上屏，隐藏档案玩家正确降级。

### FE-03 加载与状态反馈

- 展示"正在获取"进度（已查到 N/总人数）。
- 网络失败、服务器识别失败、文件格式错误分别给出明确提示（不静默）。
- 加载中防重入（同一对局不重复发起）。

### FE-04 队伍聚合与对比

- 友军/敌军平均加权胜率、平均场次、高战力玩家数。
- 战力对比的可视化（条形/数值）。

### FE-05 胜率分布图

- 展示双方胜率分布（KDE 或柱状，复用 momomi `SparklineChart` 或等价实现）。
- 跟随主题配色。

### FE-06 输出文本与复制

- 展示 Core 生成的输出文本。
- 一键复制；可选自动复制。
- 模板可配置（标签为兼容契约）。

### FE-07 观察名单交互

- 右键玩家 → 加入观察名单（Positive / Negtive / Cheater）。
- 命中观察名单的玩家在面板高亮/带图标。
- 观察名单管理界面（查看/编辑/删除，按服务器分组）。

### FE-08 对局历史

- 浏览本地留存的历史对局。
- 打开某局查看当时的名单与统计。
- 从历史跳回对应详情。

### FE-09 托盘与快捷键

- 托盘常驻（`H.NotifyIcon.WinUI`），右键菜单：显示面板、设置、检查更新、退出。
- 全局快捷键呼出/隐藏面板（复用 sox `HotkeyService`），可配置、支持冲突检测。
- 左键单击托盘呼出面板。

### FE-10 设置窗口

分组（复用 `SettingsCard` / `SettingsExpander`）：

- 常规：游戏路径（自动检测 + 手动指定）、服务器（AUTO / 具体区域）、轮询间隔。
- 战绩源与代理：源选择、代理地址、缓存策略。
- 外观：主题、材质、面板大小/位置。
- 排序与显示：排序维度、显示字段、颜色规则。
- 输出文本：模板编辑与预览。
- 更新：舰船目录与应用更新。
- 关于。

验收：设置改动即时生效（或明确提示需重启）；游戏路径能自动检测到已安装目录。

### FE-11 全屏游戏处理

- 检测前台全屏窗口（复用 sox `FullscreenDetector`）。
- 按设置：隐藏面板 / 降低刷新频率 / 不处理。
- 退出全屏后恢复。

### FE-12 应用更新

- 检查更新 → 下载 → 退出后替换并重启（复用 sox / momomi `AppUpdateService` 思路）。
- 更新保留用户数据（观察名单、设置、历史、截图、日志）。
- 船名表静默更新不打扰用户。

### FE-13 图表与视觉细节

- 卡片圆角、自绘阴影、材质（复用 sox `CardControl`）。
- 深浅色切换即时生效。

## 非功能需求

| ID | 需求 | 目标 |
|---|---|---|
| NFR-FE-01 | 常驻内存 | < 300MB |
| NFR-FE-02 | 呼出到可见 | < 100ms（常驻 + cloak） |
| NFR-FE-03 | 无 UI 线程阻塞 | 取数与解析在后台，UI 只做渲染 |
| NFR-FE-04 | 主题一致 | 所有窗口/托盘菜单跟随深浅色 |
| NFR-FE-05 | 权限 | 普通用户权限，无需管理员 |
| NFR-FE-06 | 发布 | 合并版 / 分离版双形态 |

## 与 Core 的边界

- 前端不解析 replay、不拼战绩源 URL、不识别服务器。
- 前端只调用 Core 的门面接口（见 `PRD-backend.md` 接口契约）。
- 数据读写走 `SeaMonkeys.Data`，不在前端散落文件 IO。
