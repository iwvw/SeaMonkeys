# PRD：SeaMonkeys 战舰世界实时战绩助手

> 版本：v1（2026-10-04）
> 状态：草稿，待评审
>
> 本文为总 PRD。分层需求另见 `docs/PRD-backend.md`（Core / Data / 代理）与 `docs/PRD-frontend.md`（WinUI 3 前端）。

## 背景

《战舰世界》一局随机战 24 名玩家。玩家在开局前无法判断双方实力构成，只能凭经验判断走位。社区已有同类工具（PotatoAlert、WoWs Monitor、海猴雷达 ApeRadar），验证了需求真实存在。

SeaMonkeys 的目标是做一个自用的 Windows 桌面助手：游戏写入对局元数据后自动识别本局参战名单，拉取每人战绩，在一个悬浮面板上给出双方战力对比。

约束：只读游戏写出的文件与公开接口，不注入进程、不读游戏内存，避免反作弊风险。

## 用户与模式

- 用户：作者本人及小范围分发
- 开发模式：用户观察 + Agent 实时修改
- 平台：Windows 10 1809（17763）及以上，x64 与 ARM64

## 核心场景

1. 进入对局后，悬浮面板自动弹出本局 24 人名单与战绩
2. 面板按队伍分区展示：友军 / 敌军，标注昵称、公会、舰船、等级、加权胜率、场次
3. 一眼看出双方平均战力与关键船（高战力玩家、高等级船）分布
4. 把本局统计复制为文本，粘贴到聊天或群组
5. 把特定玩家加入观察名单（Positive / Negtive / Cheater），下次遇到高亮

## 技术基线

| 项 | 内容 |
|---|---|
| 运行时 | .NET 10 LTS |
| 框架 | WinUI 3 + Windows App SDK 2.x（`net10.0-windows10.0.26100.0`） |
| 分层 | `SeaMonkeys.App`（UI）· `SeaMonkeys.Core`（零 UI 依赖）· `SeaMonkeys.Data`（SQLite） |

详见 `docs/adr/` 与 `docs/reference/wows-data-sources.md`。分层需求：`docs/PRD-backend.md`、`docs/PRD-frontend.md`。

## 功能需求

### P0（必须）

| ID | 需求 | 数据/技术支撑 |
|---|---|---|
| F-01 | 观察游戏 replay 目录，检测到新 `tempArenaInfo.json` 自动触发接入 | ADR-0002 |
| F-02 | 解析对局元数据：战斗类型、开战时间、地图、双方 24 名参与者（昵称、账号 ID、舰船 ID、关系） | ADR-0002 |
| F-03 | 排除 bot（既有标识规则 `id <= 30`） | CONTEXT 不变量 |
| F-04 | 服务器识别：读取 `profile/clientrunner.log` 的 `Selected realm`，失败时回退到跨区探测 | ADR-0004 |
| F-05 | 获取玩家账号战绩：场次、胜率、经验、伤害、公会 | ADR-0003 |
| F-06 | 获取玩家当前舰船战绩：场次、胜率、平均伤害 | ADR-0003 |
| F-07 | 加权胜率计算（账号单野/组队权重 + 舰船权重） | ADR-0003 |
| F-08 | 悬浮面板：无边框、置顶、可拖动、可缩放，默认贴第二屏 | ADR-0006 |
| F-09 | 队伍分区展示 + 按加权胜率/等级排序 | 前端 |
| F-10 | 隐藏档案降级展示（负值哨兵，不阻断其余玩家） | CONTEXT 不变量 |
| F-11 | 舰船 ID → 本地化名称/类型/等级（本地目录） | ADR-0005 |
| F-12 | 输出文本生成与一键复制（可配置模板） | 前端 |
| F-13 | 请求经代理转发，客户端不硬编码任何战绩源密钥 | ADR-0003 |
| F-14 | 请求节流与批量查询，避免触发战绩源限流 | ADR-0003 |

## 非功能需求

| ID | 需求 | 目标 |
|---|---|---|
| NFR-01 | 常驻内存 | < 300MB |
| NFR-02 | 检测到新对局到面板可读 | < 5s（取决于战绩源） |
| NFR-03 | 面板呼出到可见 | < 100ms（常驻 + DWM cloak） |
| NFR-04 | 单局请求数控制 | 24 人 + 船只，命中缓存后增量请求 |
| NFR-05 | 权限 | 普通用户权限即可，无需管理员 |
| NFR-06 | 反作弊边界 | 只读文件与公开接口，绝不注入进程或读内存 |
| NFR-07 | 发布 | 合并版 / 分离版双形态 |

## 范围外（不做）

- 不注入游戏进程、不读游戏内存、不做游戏内 overlay 覆盖
- 不做装甲计算器、弹道模拟等对局外分析（社区已有 WoWs Toolkit）
- 不托管或转发他人隐私数据

## 里程碑

| 阶段 | 内容 |
