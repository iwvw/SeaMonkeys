# ADR-0004. 服务器识别：clientrunner.log 优先，跨区探测回退

日期：2026-10-04
状态：Accepted

## 背景

对局元数据不含服务器信息（ADR-0002），而账号 ID 与战绩不跨区（同一昵称在不同区是不同账号）。因此必须先确定本局属于哪个区域，才能向正确的战绩源发起查询。

区域集合：`RU`（莱服）、`EU`、`NA`、`ASIA`、`CN`（国服）。

## 决策

**分两级：优先读游戏写出的区域日志；失败时回退到战绩源跨区探测。**

### 1. 主路径：`profile/clientrunner.log`

游戏目录 `profile/clientrunner.log` 中记录了客户端启动时选择的区域：

```
Selected realm: asia
```

取最后一次出现的值，映射为区域枚举。优点：本地读取、零网络、即时。

也允许用户在设置中手动指定区域，跳过自动识别。

### 2. 回退路径：跨区探测

当日志缺失、格式变化或手动指定为 `AUTO` 且读取失败时，用参战名单中的昵称向各区域战绩源探测：某区域的 `search` 返回命中即判定为该区域。

实测（见 `reference/wows-data-sources.md`）：同一昵称只在目标区域命中，其余区域返回空，探测具备判别力。可并行发起、先命中先返回。

### 3. 失败语义

识别彻底失败时，抛明确的"服务器识别失败"语义，**不重试**（重试不会改变本地日志内容），UI 提示用户手动指定区域。

## 备选与未选原因

- **只靠跨区探测**：每次对局都要多次网络请求，慢且浪费配额。仅作回退。
- **只靠日志**：日志格式可能随版本变化，且部分安装方式可能缺失。需回退。
- **从 replay 文件名或元数据推断**：元数据不含区域，文件名不含区域。不可行。

## 后果

- 常规路径本地即时完成，无网络开销。
- 回退路径要求代理支持跨区并行探测（ADR-0003）。
- 需在 UI 暴露手动区域选择，作为兜底。

## 关联

- ADR-0002（元数据无区域）、ADR-0003（跨区探测由代理承担）
